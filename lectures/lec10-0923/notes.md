## 1. RSA 完整流程：Gen / Enc / Dec 和正确性 ⭐

> 出处：K&L §11.5.1 Construction 11.26（书页 411）；板书 ①

### 一句话

> ==选两个大素数造出 $N$，算出一对互为逆元的指数 $e$、$d$。加密是自乘 $e$ 次，解密是再自乘 $d$ 次，正好转回原文。==

### 严格说法

**Gen**（生成钥匙，**key generation**），四步：

```
① 随机选两个 n 位的大素数 p、q               N = p·q，φ(N) = (p−1)(q−1)
② 选 e：满足 gcd(e, φ(N)) = 1               e 和 φ(N) 互素
③ 算 d：满足 e·d ≡ 1 (mod φ(N))             d 就是 e 在 mod φ(N) 下的逆元
④ 公开 pk = (N, e)，自己留着 sk = (N, d)     p、q、φ(N) 用完就扔（或者一起保密）
```

$pk$ 是公钥（**public key**），$sk$ 是私钥（**secret key**）。

**Enc**（加密，**encryption**）：$c = m^e \bmod N$

**Dec**（解密，**decryption**）：$m = c^d \bmod N$

### 例子：迷你 RSA

Lec 8 见过，现在每一步都有来历了：

```
① p = 3，q = 11          N = 33，φ(33) = 2 × 10 = 20                Lec 9 第 3 节
② e = 3                  gcd(3, 20) = 1 ✓
③ d = 7                  3 × 7 = 21 = 20 + 1 ≡ 1 (mod 20) ✓         Lec 8 第 6、7 节
④ pk = (33, 3)，sk = (33, 7)

加密 m = 4：   c = 4³ = 64 → 64 − 33 = 31
解密 c = 31：  31⁷ mod 33 = 4 ✓
```

**为什么 $e$ 必须和 $\varphi(N)$ 互素**：只有互素，$e$ 在 mod $\varphi(N)$ 下才有逆元，才找得到 $d$（Lec 8 第 6 步）。反例：$e = 2$，$\gcd(2, 20) = 2$，2 乘任何数 mod 20 都是偶数，永远凑不出 1，找不到 $d$。

### ⭐ 正确性：为什么解密能拿回 $m$

正确性（**correctness**）：

```
c^d = (m^e)^d = m^(e·d)                       (mod N)
e·d = 1 + k·φ(N)                              因为 e·d ≡ 1 (mod φ(N))
m^(e·d) = m × (m^φ(N))^k = m × 1^k = m         Euler 定理：m^φ(N) ≡ 1（Lec 9 第 5 节）
```

板书写成一行：$m^{ed \bmod \varphi(N)} = m^1 = m$，意思是指数可以先 mod $\varphi(N)$（Lec 9 第 5 节推论 1）。

大白话：==$e$ 和 $d$ 在"指数世界"里互为逆元，加密乘了 $e$ 次，解密再乘 $d$ 次，合起来等于乘了 1 次。==

### Lec 9 的每一步都在这里用上了

```
N = pq、φ(N) = (p−1)(q−1)     Lec 9 第 3 节 CRT
算 d                         Lec 8 扩展欧几里得
解密正确                      Lec 9 第 5 节 Euler 定理
外人算不出 d                  要 φ(N)，而 φ(N) 算不出来（本讲第 4 节）
```

**补一句**：这是教科书版 RSA（**plain RSA / textbook RSA**），是确定性的，同一条消息每次加密结果都一样，所以不是 CPA 安全的（Lec 8）。

### 老师板书

```
RSA  GEN:  n-bit p, q (large random primes)  →  N = p·q,  φ(N) = (p−1)(q−1)
           ⟹ e satisfying GCD(e, φ(N)) = 1   (chosen randomly)
           (p, q, e) ⟹ d:   e·d = 1 mod φ(N)
           ⟹ publish  pk = (N, e),  sk = (N, d)
c = Enc((N, e), m)  →  m^e mod N
Dec((N, d), c)  →  c^d = (m^e)^d mod N
Correctness:  m^(ed mod φ(N)) = m   mod N
```

## 2. $m^e$ 怎么算得快：反复平方

> 出处：K&L 附录 B.2.3（书页 553–555）；板书 ②

**问题**：$e$ 可能有上千位，本身就是个天文数字。笨办法是把 $m$ 连乘 $e$ 次，要乘 $2^{1000}$ 多次，永远算不完。

### 一句话

> ==把 $e$ 写成二进制，先不停地平方得到 $m, m^2, m^4, m^8, \ldots$，再把二进制里是 1 的那几项乘起来。==

这叫反复平方（**repeated squaring**），也叫 **square-and-multiply**。

### 例子：算 $m^{13}$

```
13 = 8 + 4 + 1 = 1101（二进制）

反复平方：  m → m² → m⁴ → m⁸              3 次平方
挑出来乘：  m¹³ = m⁸ × m⁴ × m¹            2 次乘法
```

一共 5 次乘法，笨办法要 12 次。数字越大，差距越悬殊。

### 带数字：迷你 RSA 的解密 $31^7 \bmod 33$

```
7 = 4 + 2 + 1 = 111（二进制）

31¹ = 31
31² = 961   → mod 33 → 4          （33 × 29 = 957）
31⁴ = 4²    = 16

31⁷ = 31⁴ × 31² × 31¹ = 16 × 4 × 31
    = 64 × 31  → 先把 64 mod 33 = 31  →  31 × 31 = 961 → mod 33 → 4   ✓
```

**关键**：==每乘一步就 mod $N$ 一次==，数字永远不超过 $N$，不会越算越大。

### 有多快

```
e 最多 2n 位                    →  最多 2n 次平方 + 2n 次乘法
每次乘法：两个 n 位级别的数相乘   →  大约 n² 次位运算
合起来                          →  大约 n³，多项式时间（polynomial time）
```

这里的"多项式"是按**位数** $n$ 算的，和 Lec 8 欧几里得算法一样。板书上写的 $N^2 \log N \sim N^3$ 就是这个意思，那里的 $N$ 指的是位数。

**为什么重要**：加密 $m^e$、解密 $c^d$ 全靠它才算得动。没有反复平方，RSA 根本用不了。

### 老师板书

```
e at most 2n bits
e = (e_2n … e_1 e_0)_2 = Σ_{t=0}^{2n} e_t · 2^t
m^e = m^(Σ e_t 2^t)
m → m² → m⁴ → m⁸ → m¹⁶ → …        每步 mod N
[m, m², m⁴, m⁸, m¹⁶, …]            大约 2n 个
N² log N ~ N³                      （N 指位数）
```

## 3. 发送方、接收方、攻击者各知道什么

> 出处：K&L §11.1（书页 375）；板书 ③

### 一句话

> ==只有接收方知道 $p, q, d$，攻击者手里只有公钥和密文。==

```
             知道什么                   能做什么
接收方 R      p、q、e、d（全部）          生成钥匙，解密
发送方 S      pk = (N, e)，自己的 m       加密：c = m^e mod N
攻击者 A      pk = (N, e)，截获的 c       只能自己加密（公钥是公开的），解不开
```

发送方（**sender**）、接收方（**receiver**）、攻击者（**adversary / attacker**）。画成图：

```
    S ──────── c ────────→ R  (p, q, e, d)
  (N, pk)         ↑
  m ∈ Z*_N        │ 偷看
                  A   pk = (N, e)，c
```

### 要注意的两点

1. **攻击者也有公钥**。所以他随时能自己加密任何消息，这就是 Lec 8 说的"公钥加密天然是 CPA"。确定性的 textbook RSA 在这里就露馅了：攻击者猜一个 $m$，自己加密一下，和 $c$ 对比就知道猜没猜对。
2. **攻击者和解密之间，只差一个 $d$**。算 $d$ 要用 $\varphi(N)$，所以问题就变成了"攻击者能不能从 $N$ 算出 $\varphi(N)$"，这就是第 4 节。

### 老师板书

```
S: (N, pk),  m ∈ M = Z*_N
R: (p, q, e, d)
A: pk = (N, e),  c
```

## 4. 攻击者能算出 $\varphi(N)$ 吗？⭐

> 出处：K&L §8.2.4（书页 312–313）；板书 ④

### 一句话

> ==不能。谁要是知道了 $\varphi(N)$，用初中的求根公式就能把 $N$ 分解掉，而分解是公认很难的。==

### 推导：知道 $N$ 和 $\varphi(N)$，怎么算出 $p, q$

```
φ(N) = (p−1)(q−1) = pq − p − q + 1 = N − (p + q) + 1

所以    p + q = N − φ(N) + 1          两个数的和，算出来了
而      p × q = N                      两个数的积，本来就知道
```

**知道两个数的和与积，它们就是一个一元二次方程的两个根**：

$x^2 - (p + q)\,x + pq = 0$

用求根公式（**quadratic formula**）一解，$p, q$ 就出来了。

### 例子：$N = 33$，假如攻击者知道 $\varphi(33) = 20$

```
p + q = 33 − 20 + 1 = 14
p × q = 33

x² − 14x + 33 = 0
x = (14 ± √(196 − 132)) / 2 = (14 ± 8) / 2   →   x = 11 或 3      ✓ 分解出来了
```

### 这说明了什么

```
知道 p、q    ⟹   能算 φ(N) = (p−1)(q−1)           显然
知道 φ(N)    ⟹   能算 p、q                       上面的求根公式
```

两个方向都通，所以 ==算 $\varphi(N)$ 和分解 $N$ 一样难==。

这是一个归约（**reduction**），和 Lec 7 学的证明方法一样：

> 如果攻击者能算 $\varphi(N)$，他就能分解 $N$。
> 分解 $N$ 很难 ⟹ 他算不出 $\varphi(N)$ ⟹ 他算不出 $d$ ⟹ 他没法用正常方式解密。

**补一句**：这只堵住了"先算 $d$ 再解密"这条路。会不会有别的办法，不用 $d$ 也能从 $c$ 算出 $m$？目前没人找到，这被当作一个假设，叫 RSA 假设（**RSA assumption**，K&L Definition 8.46）。

### 老师板书

板书是直接代入 $p = N/q$，最后得到的是同一个方程：

```
Can attacker know φ(N)?   No.  Can compute q using quadratic formula
φ(N) = (p−1)(q−1),   N = pq  ⟹  p = N/q
q·φ(N) = (N − q)(q − 1) = −q² + (N+1)q − N
q² + (φ(N) − N − 1)·q + N = 0   ⟹   q → p
```

## 5. 单向函数正式定义 + one-way permutation

> 出处：K&L §7.1 Definition 7.1、7.2（书页 243–244）；板书 ⑤；接 [Lec 9 笔记](../lec09-0921/notes.md)第 6 节

Lec 9 第 6 节已经讲过意思（正着易、倒着难）和 4 个细节。这里只补老师板书的**正式写法**，以及一个新名词 one-way permutation。

### 先认两个记号

```
{0,1}^n     所有长度为 n 的 0/1 串（比如 n = 3：000, 001, …, 111，共 8 个）
{0,1}^*     任意长度的 0/1 串
```

### 正式定义

> **DEFINITION 7.1**（板书写法）$f: \{0,1\}^n \to \{0,1\}^*$ 是单向函数（**one-way function**），要满足：
>
> 1. 正着好算（**forward efficiency**）：任给 $x$，$f(x)$ 能在 $\mathrm{poly}(\lvert x \rvert)$ 时间内算出来；
> 2. 倒着难（**average-case hard**）：对任何多项式时间的攻击者 $A$，$\Pr_{x \leftarrow \{0,1\}^n}\big[f(A(f(x))) = f(x)\big] < \mathsf{negl}(n)$。

**第 2 条那个式子从里往外读**：

```
f(x)                 把随机选的 x 算一下，交给攻击者
A(f(x))              攻击者看着 f(x)，吐出一个猜测 x′
f(A(f(x))) = f(x)    检查：f(x′) 是不是等于 f(x)？        等于就算他赢
Pr[…] < negligible   他赢的概率可以忽略
```

这就是 Lec 9 第 6 节细节 1、2 的正式写法：==猜到任意一个原像就算赢==（检查的是 $f(x') = f(x)$，不是 $x' = x$），$x$ 是随机选的（平均情况难）。

**例子：板书的 $f_{mult}$**

```
f_mult(p, q) = p × q = N           输入两个 n 位的数（共 2n 位），输出 N（约 2n 位）
倒推：给定 N，找 p、q 使 p × q = N    就是分解，难
```

（Lec 9 第 6 节细节 3：$p, q$ 要限定成等长的素数，不然乘积多半是偶数，一拆就开。）

### One-way permutation

> **DEFINITION 7.2** 单向置换（**one-way permutation**）：本身是一个置换的单向函数，也就是把所有输入"重新排座位"，不重不漏（Lec 9 第 1 节的置换）。

```
普通单向函数：   可能好几个 x 对应同一个 f(x)，倒推时找到任意一个就算赢
单向置换：       每个 f(x) 只对应唯一一个 x，倒推 = 必须找回原来那个 x
```

**例子：RSA 本身就是一个（猜想中的）单向置换**

- **是置换**：$x \mapsto x^e \bmod N$ 把 $\mathbb{Z}^*_N$ 里的数重新排了一遍，不重不漏（Lec 9 第 5 节，Corollary 8.22）。
- **单向**：没有 $d$，倒推不出 $x$（第 4 节，加上 RSA 假设）。
- 而且是带后门的：有 $d$ 就能倒推，叫 **trapdoor permutation**（Lec 18）。

反例：$f_{mult}$ 不是置换，因为 $(3, 11)$ 和 $(11, 3)$ 都得到 33，撞了。

**用一个能列全的小 RSA 看清楚**：$N = 15$，$e = 3$（$\varphi(15) = 8$，$\gcd(3, 8) = 1$）。$\mathbb{Z}^*_{15} = \{1, 2, 4, 7, 8, 11, 13, 14\}$，每个数算一下 $x^3 \bmod 15$：

```
x      1   2   4   7   8   11   13   14
x³     1   8   4   13  2   11   7    14
```

- **是置换**：下面一行还是这 8 个数，一个不多、一个不少、没有重复，只是换了座位。所以每个密文只对应唯一一个明文，解密结果是确定的。
- **单向**：没有私钥的人拿到密文 13，这里只有 8 个数，查表就知道是 7；可真实的 $N$ 有 2048 位，表根本列不出来，就倒推不回去。
- **带后门**：有私钥 $d = 3$（$3 \times 3 = 9 \equiv 1 \bmod 8$）的人直接算：$13^3 \bmod 15 = 2197 \bmod 15 = 7$，一步就回来了。

### 老师板书

```
f_mult[p, q] → N         (n-bit each)      {0,1}^2n → {0,1}^2n
Given N hard to find p, q such that pq = N          f⁻¹
One-way functions:  Let f: {0,1}^n → {0,1}^*
  • ∀ x ∈ {0,1}^n, f(x) can be computed in poly(|x|)       [Forward efficiency]
  • Average-case hard:  for uniformly selected x ∈ {0,1}^n,
    it is hard to recover x when only given f(x)
    ∀ poly-time A,  Pr_{x~U} [ f(A(f(x))) = f(x) ] < neg.
one way permutation
```

## 6. 单向 ≠ 什么都不漏：partial info can leak

> 出处：K&L §7.1.3（书页 247）；板书 ⑥

### 一句话

> ==单向函数只保证"整个输入倒推不回来"，不保证"一点信息都不漏"。它甚至可以把一半输入原封不动地露出来。==

### 板书的构造

手里有一个单向函数 $f$，用它造一个新函数 $g$：输入分成前后两半 $x$ 和 $x'$，

$g(x, x') = (f(x),\ x')$

前一半过一遍 $f$，后一半原样输出。**$g$ 把一半输入直接露出来了，但它照样是单向的**：

- **后一半 $x'$**：直接写在输出里，攻击者一眼就看到了。
- **前一半 $x$**：要从 $f(x)$ 倒推，而 $f$ 是单向的，推不回来。
- **倒推 $g$** 要找回完整的输入，前一半找不回来，所以整体还是倒推不了，$g$ 满足单向函数的定义。

### 例子

用第 5 节的小 RSA，$f(x) = x^3 \bmod 15$：

```
g(7, 5) = (7³ mod 15, 5) = (13, 5)
```

攻击者直接看到了后一半是 5；前一半的 7 要从 13 倒推（真实的 $N$ 很大时推不回来）。**漏了一半，但仍然是单向函数。**

### 为什么这很重要

- 加密要的是**什么都不漏**：Lec 7 讲的 semantic security，密文不能泄露明文的任何信息。
- "单向"这个要求**弱得多**：只要求不能整个倒推回去，漏掉一部分（**partial information**）完全允许。

所以问题来了：**RSA 是单向的，那它会不会也漏掉明文 $m$ 的某些位？**

第 8 节回答了其中一位：$m$ 的最低位 $m_0$ 是藏得住的，能猜出 $m_0$ 就能恢复整个 $m$。这种藏得住的位叫硬核位（**hard-core bit / hard-core predicate**，K&L Definition 7.4，Lec 18 细讲）。

### 老师板书

```
motivation, partial info can leak
Enc^RSA(m) = m^e mod N
f is one-way   {0,1}^n → {0,1}^*
Let g: {0,1}^2n → {0,1}^*   as   g[x · x′] := [f(x), x′]      x′ leak
g is also one-way
```

## 7. RSA 的乘法同态

> 出处：K&L §11.5；板书 ⑦

### 一句话

> ==两条消息先乘再加密，等于先各自加密再乘。所以攻击者不知道 $m$，也能把密文 $c$ 改成 $2m$ 的密文。==

### 严格说法

$\mathrm{Enc}(a \cdot b) = (ab)^e = a^e \cdot b^e = \mathrm{Enc}(a) \cdot \mathrm{Enc}(b) \pmod N$

这叫乘法同态（**multiplicatively homomorphic**）。它和 Lec 9 第 2 节同构的第 2 条长得一模一样：$f(g_1 \circ g_2) = f(g_1) \circ f(g_2)$，先算再翻译 = 先翻译再算。

### 板书用的特例：把 $m$ 翻倍

$\mathrm{Enc}(2m) = \mathrm{Enc}(2) \cdot \mathrm{Enc}(m) = 2^e \cdot c \pmod N$

**关键**：$2^e$ 谁都能算，因为 $e$ 是公开的。所以攻击者**不知道 $m$**，只要拿截获的 $c$ 乘上 $2^e$，就得到了 $2m$ 的密文。

### 例子：迷你 RSA，$N = 33$，$e = 3$

```
m = 4 的密文：      c = 31                           （第 1 节算过）
Enc(2) = 2³ = 8
8 × 31 = 248  →  mod 33 = 248 − 231 = 17

验证：直接加密 2m = 8：   8³ = 512 → mod 33 = 512 − 495 = 17   ✓ 一样
```

攻击者全程没碰到 $m = 4$，却造出了 8 的密文。

### 好事还是坏事？两面都有

- **坏事**：攻击者能有意义地篡改密文。比如密文里是转账金额，他不用解密，就能把金额改成原来的 2 倍。这个性质叫可延展（**malleable**）。
- **好事**：Lec 1 提到的同态加密（**homomorphic encryption**），就是想在不解密的情况下对密文做计算。
- **本讲的用处**：第 8 节的证明，就是靠这招把 $c$ 变成 $\mathrm{Enc}(2m)$、$\mathrm{Enc}(4m)$……，一步步套出 $m$。

### 老师板书

```
Homomorphic for ×                                  Used for proof.
c = Enc(m)
Enc(2m) = (2m)^e mod N = 2^e · m^e mod N
Enc^RSA(ab) = Enc^RSA(a) · Enc^RSA(b) = Enc(2) · Enc(m) mod N
            = Enc(2) · c
```

## 8. 证明：RSA 和最低位一样安全（二分查找）⭐

> 出处：K&L §11.5.3（书页 417）；板书 ⑧

### 一句话

> ==猜 RSA 明文的最低位 $m_0$，和破解整个 RSA 一样难。所以 RSA 破不了，最低位就藏得住（**RSA is as safe as $m_0$**）。==

### 要证什么

**如果有人能从密文 $c$ 猜出 $m$ 的最低位 $m_0$（也就是 $m$ 是奇是偶），那他就能恢复整个 $m$。**

证明方法是归约（**reduction**），和 Lec 7 一样：假设有个算法 $A$ 能猜最低位，**拿 $A$ 当工具**造出一个能恢复整个 $m$ 的算法。

### 先看类比：猜数游戏

我心里想一个 1~100 的数。你每猜一次，我告诉你"大了"还是"小了"，最多 7 次就能猜中，这就是二分查找（**binary search**）。

**但如果我什么都不说，你就只能瞎猜。** 二分查找能成功，全靠"大了/小了"这个回答。

==能猜最低位的 $A$，其实就是那个回答"大了/小了"的朋友换了个样子。== 下面说为什么。

### 核心观察：$2m \bmod N$ 的奇偶 = $m$ 在前半还是后半

$N$ 是奇数（两个奇素数相乘）。拿 $N = 15$ 看：

```
m 在前半段（0~7）：   2m = 0, 2, 4, …, 14        没超过 15，不用减        → 偶数
m 在后半段（8~14）：  2m = 16, 18, …, 28
                     mod 15 要减一次 15 → 1, 3, …, 13                  → 奇数
```

偶数减去奇数 15，就变成了奇数。所以：

```
2m mod N 的最低位是 0（偶）   ⟺   m 在前半段
2m mod N 的最低位是 1（奇）   ⟺   m 在后半段
```

**问"$2m$ 的最低位"，就等于问"$m$ 在前半还是后半"。**

### 怎么问 $A$：用第 7 节的同态

我们不知道 $m$，只有 $c$。但 $\mathrm{Enc}(2m) = \mathrm{Enc}(2) \cdot c$，谁都能算。把它交给 $A$，$A$ 就告诉我们 $m$ 在哪一半。

同理，交 $\mathrm{Enc}(4m)$ 就知道在哪四分之一，交 $\mathrm{Enc}(8m)$ 就知道在哪八分之一……**每问一次，范围砍一半。**

### 例子：$N = 15$，秘密 $m = 7$（我们不知道，只有 $c$）

```
问 2m：   2×7 = 14 → 偶 → 0      m 在前半       范围 {0, …, 7}
问 4m：   28 → 13 → 奇 → 1       在前半的后半   范围 {4, 5, 6, 7}
问 8m：   56 → 11 → 奇 → 1       再取后半       范围 {6, 7}
问 16m：  112 → 7 → 奇 → 1       再取后半       范围 {7}          ✓ 找到 m = 7
```

中间每一次的结论都是"上一次剩下的范围，取前半还是后半"，道理和第一次一样。

### 有多快

$N$ 有 $n$ 位，每问一次砍一半，**问 $n$ 次就只剩一个数**。每次问之前算 $\mathrm{Enc}(2^k) \cdot c$，用第 2 节的反复平方很快，所以整体是多项式时间。

### ⭐ 整个证明的逻辑

```
假设：有一个 A，能从密文猜出最低位
  ⟹  把 Enc(2m)、Enc(4m)… 交给 A，每次得到一个"前半/后半"
  ⟹  二分查找，n 次就找到整个 m
  ⟹  RSA 被完全破解

但大家相信 RSA 破不了（RSA 假设）
  ⟹  这样的 A 不存在
  ⟹  没人能从密文猜出最低位
```

所以这个证明**不是在教你怎么破解 RSA**，而是在说：==猜最低位和破解整个 RSA 一样难。== 最低位因此是一个硬核位（**hard-core bit**，第 6 节）。

**考试要会的**：$N$ 是奇数这个关键；$2m \bmod N$ 的奇偶和"前半/后半"的对应；怎么用同态得到 $\mathrm{Enc}(2m)$；每次砍一半，所以 $n$ 次问完。

**补一句**：板书假设 $A$ **每次都答对**。书上（§11.5.3）处理的是 $A$ 只比瞎猜好一点点的情况，难得多，不要求。

### 老师板书

```
Proof, RSA is as safe as m₀ bits.      [m_2n, …, m_1, m_0] ∈ Z*_N
Enc^RSA(m) = m^e mod N
If A that obtain m₀ from Enc^RSA(pk, m) in p-time,
then I can compute m in polynomial time.
Z*_N = {1, 2, …, N−1}     N odd
[2m]₀:   2m 没超过 N → 偶；超过 N → 减 N → odd
C = Enc^RSA(m),   C₂ = Enc^RSA(2m),   C₄ = Enc(4m) …       A(C₂)
can eliminate half every time using binary search.    N-iteration（N 指位数）
```
