## 1. 为什么需要公钥：钥匙分发问题

> 出处：K&L §10.1、§10.4（书页 359–360、370–374）；板书 ①

### 问题：钥匙最开始怎么共享？

Lec 4–7 的私钥加密都假设**双方已经有同一把钥匙**。但这把钥匙不能直接在网上发，会被窃听。

三个麻烦（§10.1）：

```
① 分发：    只能见面交接，或派信使送（Lec 4 的"红色电话"就是这么干的）
② 管理：    N 个人两两通信，每人要存 N−1 把
            N = 1000 时，全公司一共 499,500 把
③ 开放系统：网购时和从没见过的商家通信，根本没机会事先交换钥匙
```

①② 在封闭组织里还能勉强解决（设一个大家都信任的密钥分发中心，§10.2）；==③ 私钥加密完全解决不了==。

### 解决：公钥加密（Diffie & Hellman，1976）

每人生成**一对**钥匙：**公钥 $pk$** 公开、用来加密；**私钥 $sk$** 保密、用来解密。

==知道公钥也解不开==，所以公钥可以大方地挂在网上。

**类比：带投信口的信箱**

```
公钥  =  投信口     谁都能把信塞进去（谁都能加密）
私钥  =  信箱钥匙   只有主人能取信（只有主人能解密）
```

三个麻烦都解决了：

```
① 公钥直接公开发      ② 每人只保管自己一把私钥      ③ 商家把公钥挂在网站上即可
```

### 私钥 vs 公钥：一把钥匙变成两把

```
之前（私钥 / 对称）：   一把钥匙 k
                       Enc_k(m) → c        加密用 k
                       Dec_k(c) → m        解密也用 k
                       k 必须双方都有，还得保密

现在（公钥 / 非对称）： 一对钥匙 (pk, sk)
                       Enc(pk, m) → c      加密用公钥
                       Dec(sk, c) → m      解密用私钥
                       pk 公开给所有人，sk 只有接收方有
```

补两点：

1. **两把钥匙不是各自随便选的**，是 $\mathrm{Gen}$ 一次**成对**生成的，数学上配套。用 $pk$ 加密的东西，只有配套的 $sk$ 能解开。
2. ==攻击者也知道 $pk$==，因为它是公开的。这是和之前最大的不同，第 3 步 CPA 就从这里来：攻击者手里有 $pk$，想加密什么就能自己加密什么。

### 这节还是在讲加密

钥匙分发只是**动机**，这节的主角是**公钥加密**：

```
Lec 4–7   私钥加密          前提：双方已经有同一把钥匙
Lec 8     钥匙怎么来？ → 换成公钥加密 → 准备数论工具
Lec 9–10  RSA：第一个具体的公钥加密方案
```

私钥加密没有被淘汰。现实中（比如 HTTPS）两者配合：先用公钥的方法安全地商量出一把钥匙，再用它做私钥加密——私钥加密快得多，公钥加密慢，只用来传钥匙。专门讲"商量钥匙"的是 Lec 12 的 Diffie–Hellman 密钥交换。

### 历史

```
1976  Diffie & Hellman 提出公钥的想法（板书上的 Diffie-Hellman），但没给出加密方案
1977  RSA：第一个公钥加密方案（Lec 9、10）
1985  El Gamal（Lec 14）
```

## 2. 公钥加密的语法和正确性

> 出处：K&L §11.1、§11.2（书页 375–379）；板书 ①

### 严格说法

> **DEFINITION 11.1** 公钥加密方案是三个 ppt 算法 $(\mathrm{Gen}, \mathrm{Enc}, \mathrm{Dec})$：
>
> 1. $\mathrm{Gen}(1^n)$ 输出一对钥匙 $(pk, sk)$，分别叫**公钥**和**私钥**。
> 2. $\mathrm{Enc}$ 输入公钥 $pk$ 和消息 $m$，输出密文，记作 $c \leftarrow \mathrm{Enc}_{pk}(m)$。（$\mathrm{Enc}$ 要做到有意义的安全，必须是随机的。）
> 3. $\mathrm{Dec}$ 是**确定性**的，输入私钥 $sk$ 和密文 $c$，输出消息 $m$ 或失败符号 $\bot$，记作 $m := \mathrm{Dec}_{sk}(c)$。
>
> **正确性：** 除了可忽略的概率外，对 $\mathrm{Gen}(1^n)$ 输出的 $(pk, sk)$ 和任意合法消息 $m$，都有 $\mathrm{Dec}_{sk}(\mathrm{Enc}_{pk}(m)) = m$。

### 大白话

```
Gen  =  造钥匙的机器，一次吐出配套的两把：公钥、私钥
Enc  =  用公钥上锁（谁都能做）
Dec  =  用私钥开锁（只有主人能做）

正确性 = 用公钥锁上，用配套的私钥打开，能拿回原件
```

### 和私钥版（Lec 4）比，变了什么

| | 私钥 | 公钥 |
| :--- | :--- | :--- |
| Gen 输出 | 一把 $k$ | **一对** $(pk, sk)$ |
| 加密、解密用 | 同一把 $k$ | 加密用 $pk$，解密用 $sk$ |
| Enc 随机吗 | 可以随机 | ==**必须随机**==（第 3 步讲为什么） |
| 正确性 | 100% 成立 | 允许**可忽略概率**出错 |

**为什么允许出错？** 造钥匙时要随机找大素数，用的是 Lec 7 讲的那种随机测试，有极小概率把合数误当成素数，钥匙就坏了。概率可忽略，所以允许。

### 例子：迷你版 RSA（Lec 9 的预告）

```
Gen：   选 p = 3，q = 11，得到
        公钥 pk = (33, 3)      ← 公开
        私钥 sk = 7            ← 保密

Enc：   c = m³ mod 33
Dec：   m = c⁷ mod 33

加密 m = 4：   4³ = 64 = 33 + 31          →  c = 31
解密 c = 31：  31⁷ mod 33 = 4             →  拿回 m = 4 ✓
```

谁都能拿 $(33, 3)$ 去加密，但只有知道 $7$ 的人能解密。这些数是怎么来的，Lec 9 讲。

注意这个迷你版==每次加密结果都一样==（确定性的），第 3 步会看到这正是它的问题。

### 老师板书

```
GEN → (pk, sk)
Enc(pk, m) → c
Dec(sk, c) → m
Correctness: ∀ m ∈ M, ∀ (pk, sk):  Dec(sk, Enc(pk, m)) = m
```

和书上一样。老师写的是"对所有钥匙都成立"的严格版；书上多放宽了一点，允许可忽略概率出错。

## 3. CPA：选择明文攻击

> 出处：K&L §3.4.2 Definition 3.22、Theorem 3.21（书页 72–75）；§11.2.1 Definition 11.2、Proposition 11.3、Theorem 11.4（书页 379–381）；板书 ②

### 一句话

> ==攻击者不只能偷看密文，还能自己挑明文，让系统替他加密。==

Lec 6 的四种攻击模型里，这是第 ③ 种。

### 真实例子：中途岛战役（1942）

```
美军截获日军密电，破译出一部分：日军要进攻 "AF"，但不知道 AF 是哪
美军怀疑是中途岛，于是故意让中途岛发一条假消息："我们缺淡水了"
日军截获后，加密上报："AF 缺淡水"
美军再截获这条密电 → 确认 AF = 中途岛
```

美军**控制了日军要加密的内容**，这就是选择明文攻击。

### 严格说法：CPA 实验（私钥版）

和 Lec 7 第 3 节的猜谜游戏一样，**只多了一样东西：攻击者全程可以用一台"加密机"** $\mathrm{Enc}_k(\cdot)$：

> 实验 $\mathsf{PrivK}^{\mathsf{cpa}}_{A,\Pi}(n)$：
>
> 1. 运行 $\mathrm{Gen}(1^n)$ 生成钥匙 $k$。
> 2. $A$ 收到 $1^n$，可以随便使用加密机，然后输出两条等长的消息 $m_0, m_1$。
> 3. 均匀抽取 $b \in \{0,1\}$，把 $c \leftarrow \mathrm{Enc}_k(m_b)$ 交给 $A$。
> 4. $A$ 还可以继续使用加密机，最后输出 $b'$。
> 5. 若 $b' = b$，实验输出 1（$A$ 成功）。

> **DEFINITION 3.22（CPA-secure）** 若对每个 ppt 攻击者 $A$，存在可忽略函数 $\mathsf{negl}$，使得
>
> $\Pr[\mathsf{PrivK}^{\mathsf{cpa}}_{A,\Pi}(n) = 1] \le \tfrac12 + \mathsf{negl}(n)$

加密机里装着钥匙 $k$，攻击者看不到 $k$，只能喂明文、拿密文。书上叫它 **encryption oracle**。

### ⭐ 反直觉的结论：确定性加密一定不 CPA 安全

**确定性** = 同一条消息，每次加密结果都一样。攻击者这样打：

```
1. 先用加密机加密 m₀，记下结果 c₀
2. 拿到挑战密文 c 后，比一下：
   c = c₀  →  猜 b' = 0
   c ≠ c₀  →  猜 b' = 1
```

**百分之百赢。**（K&L Theorem 3.21、11.4）

**拿第 2 节的迷你 RSA 看：** 它是确定性的，4 永远加密成 31。攻击者拿公钥自己加密一下 4，得到 31，再和截获的密文一比，就知道是不是 4。

> ==CPA 安全的加密必须是随机的==：同一条消息每次加密出**不同**的密文，但都能正确解密回来。怎么做到，后面会学。

这不是定义太苛刻。书上的例子：学生加密一串"对/错"答案，如果是确定性的，看密文就知道哪些题答案相同。

### 公钥版：窃听安全自动就是 CPA 安全

公钥版的窃听游戏 $\mathsf{PubK}^{\mathsf{eav}}_{A,\Pi}(n)$（Def 11.2）只改了一处：**攻击者一开始就拿到公钥 $pk$**。

```
攻击者有 pk  →  想加密什么，自己算就行
            →  等于免费送了他一台加密机
            →  窃听安全 = CPA 安全（Proposition 11.3）
```

对比私钥版：OTP 是窃听安全的，但**不是** CPA 安全的（钥匙复用就破，Lec 4 讲过）。

所以对公钥来说，==确定性的方案连最基本的窃听安全都做不到==（Theorem 11.4）。迷你 RSA 就是这种，真实的 RSA 加密要先加随机填充。

### 顺带一个结论：公钥加密不可能完美保密

算力无限的攻击者手里有 $pk$，可以把所有消息、所有随机数都试一遍加密，看哪个能得到截获的密文，就知道原文了。所以**公钥加密只能是计算安全的**，Lec 7 那套计算安全的框架是必需的。

### 老师板书

```
Nature of attacks:  Chosen-plaintext attack (CPA)
Supervised learning
```

右边那个 Supervised learning 是老师的 crypto × ML 线索（Lec 6）：CPA 就像攻击者能**自己挑输入、拿到带标签的样本**（明文 → 密文）去学习加密函数。

## 4. GCD 与欧几里得算法

> 出处：K&L 附录 B.1.2（书页 550–551）；板书 ③

### 一句话

> ==欧几里得算法（辗转相除）求 gcd，是多项式时间的。==

做法在 [HW1 Problem 1(a)](../../homework/hw1/hw1-fengcheng-private-part1.md) 用过（求 $3^{-1} \bmod 17$ 的第一步）。这一步新的只有两点：**为什么对、为什么快**。

### 算法

板书就是这段代码：

```
GCD(a, b):                  （a ≥ b > 0）
    if b | a:  return b
    else:      return GCD(b, a mod b)
```

例子：

```
gcd(15, 6)：       15 = 2 × 6 + 3
                    6 = 2 × 3 + 0          →  3

gcd(1071, 462)：   1071 = 2 × 462 + 147
                    462 = 3 × 147 + 21
                    147 = 7 × 21  + 0      →  21
```

### 为什么对

> $\gcd(a, b) = \gcd(b,\ a \bmod b)$（K&L Proposition B.6）

大白话：$(a, b)$ 和 $(b,\ a \bmod b)$ 的**公因数是同一批数**，最大的那个自然也一样。所以把大数换成余数，问题变小了，答案不变。

老师没证明这条，记住这一句就够。

### ⭐ 为什么快：多项式时间

**Claim：** 若 $a > b$，则 $a \bmod b \le a/2$。

分两种情况：

```
b ≤ a/2：   余数 < b ≤ a/2
b > a/2：   a 里只装得下一个 b，余数 = a − b < a/2
```

由 Claim 推出：

```
每走两步，数字至少减半      （走两步后，a 变成了 a mod b）
每减半一次，少一位          （b 一共 bits(b) 位）
⟹  最多 2 × bits(b) 步    ⟹  多项式时间
```

==多项式时间是按**位数**算的，不是按数值大小算的==，和 Lec 7 里 $1^n$ 是同一个道理。

例子：两个 1024 位的数

```
欧几里得：       最多 2048 步（随机取两个数实测：634 步）
挨个试公因数：   要试约 2^1024 个，永远算不完
```

RSA 要对上千位的数求 gcd、求逆元，靠的就是它快。

### 老师板书

```
Number theory and Alg.
Integers Z, Z⁺      + × ÷          ← ÷ 圈起来了：带余除法是核心
GCD(a,b) = GCD(b,a)
GCD(a,b) = GCD(b, a mod b)
[d] = GCD(a,b):
    if b|a ⟹ d = b
    else return GCD(b, a mod b)
polynomial time
terminates in 2 × bits(b)
Claim a > b:  a mod b ≤ a/2
    b ≤ a/2  ⟹  a mod b < b ≤ a/2
    b > a/2  ⟹  a mod b = a − b < a/2
```

左边的 `GCD(6,15) = 3`、`−2×6 + 1×15 = 3` 属于第 5–7 步（把 gcd 写成 $a$、$b$ 的组合）。

## 5. 定理：GCD 是 $I_{ab}$ 里最小的正数 ⭐

> 出处：K&L §8.1.1 Proposition 8.2（书页 288）；板书 ④

### 严格说法

$I_{ab} = \{Aa + Bb \mid A, B \in \mathbb{Z}\}$

> **PROPOSITION 8.2** 设 $a, b$ 为正整数，则 $\gcd(a, b) \in I_{ab}$，而且是 $I_{ab}$ 里**最小的正数**。

### 大白话

```
I_ab  =  用 a 和 b 能凑出来的所有数（a 拿 A 份、b 拿 B 份，A、B 可以是负数）
定理  =  能凑出来的最小正数，就是 gcd
```

### 例子：$a = 6$，$b = 15$

```
能凑出：  6,  15,  9 = 15 − 6,  3 = −2×6 + 1×15,  0,  −3, ...
```

- 凑不出比 3 小的正数：6 和 15 都是 3 的倍数，怎么加减都还是 3 的倍数。
- 3 本身能凑出来：$-2 \times 6 + 1 \times 15 = 3$。

所以最小的正数是 $3 = \gcd(6, 15)$。其实 $I_{ab}$ 就是 3 的全部倍数。

### ⭐ 证明：两句话

记 $d = \gcd(a, b)$，$d^*$ = $I_{ab}$ 里最小的正数。

**第一句（简单）：凑出来的数全是 $d$ 的倍数，所以 $d^* \ge d$。**

```
d 整除 a 和 b   ⟹  d 整除任何 Aa + Bb   ⟹  d 整除 d*   ⟹  d* ≥ d
```

**第二句（难点）：$d^*$ 能整除 $a$ 和 $b$，所以 $d^* \le d$。**

只靠一个事实：==凑出来的数相减，结果还是凑出来的。==

用反证。假如 $d^*$ 去除 $a$ 除不尽：

```
a = c·d* + r，余数 0 < r < d*
r = a − c·d*      ← a 能凑，d* 能凑，相减也能凑
```

$r$ 能凑出来，是正数，还比 $d^*$ 小，这和"$d^*$ 是最小的正数"矛盾。所以 $d^*$ 能整除 $a$，$b$ 也一样。能整除 $a$ 和 $b$ 就是公因数，公因数不会超过最大公因数，所以 $d^* \le d$。

用 6 和 15 走一遍：

```
假如最小的是 6：   15 = 2×6 + 3
                  余数 3 = 15 − 2×6 也能凑，还比 6 小   →  6 不是最小的
假如最小的是 3：   6 = 2×3 + 0，15 = 5×3 + 0
                  余数都是 0，找不到更小的              →  没矛盾
```

> ==最小的那个数要是除不尽，余数就是一个更小的正数，所以它一定除得尽。==

**两句合起来**：$d^* \ge d$ 且 $d^* \le d$，所以 $d^* = d$。

### 为什么打 ⭐

定理说 gcd 本身能凑出来，所以 ==gcd 一定能写成 $Xa + Yb$==。$\gcd(a, n) = 1$ 时就是 $Xa + Yn = 1$，这里的 $X$ 就是 $a$ 在 mod $n$ 下的逆元（第 6 步）。$X$、$Y$ 具体怎么算，是第 7 步。

### 老师板书

```
d* = d                                                   ← 结论（写在最上面）
Theorem ∀a,b ∈ Z,  d = GCD(a,b) ∈ I_ab
        and is the smallest positive number in I_ab
Proof   Suppose d = GCD(a,b)
        Let d* be the smallest positive element of I_ab  设 d* 是最小正数
        Claim d* also divides everyone in I_ab           第二句（a、b 也在 I_ab 里）
        ∃c, r:  Aa + Bb = c·d* + r                       用 d* 去除，余数是 r
                d* ∈ I_ab,  d* = Xa + Yb                 d* 也是凑出来的
        r = Aa + Bb − c[Xa + Yb] = [A − cX]a + [B − cY]b 余数也能凑出来 → 只能是 0

右边那块：
        d = GCD(a,b) = biggest factor common of a & b
        IF d|a, d|b ⟹ ∀A, B ∈ Z ...                     第一句
        I_ab = {Aa + Bb | A ∈ Z, B ∈ Z}
```

老师证的是 $I_{ab}$ 里任意一个数 $Aa + Bb$，其实只用得到 $a$ 和 $b$ 这两个（$a = 1 \cdot a + 0 \cdot b$）。

## 6. 互素与 Bézout（复习）

> 出处：K&L §8.1.1、§8.1.2 Proposition 8.7（书页 288–290）；板书 ⑤；已在 [HW1 Problem 1](../../homework/hw1/hw1-fengcheng-private-part1.md) 和 [有限域笔记](../../homework/hw1/notes-finite-fields.md) 练过

### 一句话

> ==$b$ 在 mod $N$ 下有逆元 $\iff \gcd(b, N) = 1$，即 $b$ 和 $N$ 互素==（Proposition 8.7）

### 串起来

```
gcd(b, N) = 1   ⟺   b、N 互素                        （定义）
                ⟺   存在 X, Y 使 X·b + Y·N = 1       （Bézout，第 5 步的定理给出）
                ⟺   b 在 mod N 下有逆元，逆元就是 X    （两边 mod N，Y·N 那项变成 0）
```

### 例子

```
7⁻¹ mod 17：    1 = 5×7 − 2×17        →  7⁻¹ = 5
mod 12 里的 4： gcd(4, 12) = 4         →  凑出来的全是 4 的倍数，凑不出 1，没有逆元
迷你 RSA：      3 × 7 = 21 = 20 + 1    →  私钥 7 = 3⁻¹ mod 20
8 和 9：        都不是素数，但 gcd = 1  →  互素（互素不要求两个数本身是素数）
```

### 老师板书

```
a and b are relatively prime if GCD(a,b) = 1
⟹ ∃ X, Y such that  Xa + Yb = 1
```

## 7. 扩展欧几里得：从手算到递归算法

> 出处：K&L 附录 B.1.2 Algorithm B.10（书页 552）；板书 ⑥

手算（辗转相除 + 回代）在 [HW1 Problem 1(a)](../../homework/hw1/hw1-fengcheng-private-part1.md) 做过。这一步是把它写成递归算法：==往下调 = 辗转相除，往上返回 = 回代。==

### 代码

输出 $[d, X, Y]$，满足 $d = \gcd(a, b) = Xa + Yb$。和第 4 步的普通版比，只改了两个地方：

```
普通版（第 4 步）                      扩展版（第 7 步）
if b | a:  return b                   if b | a:  return [b, 0, 1]
else:      return GCD(b, a mod b)     else:      a = c·b + r
                                                 [d, A, B] = ExtGCD(b, r)
                                                 return [d, B, A − B·c]
```

### 为什么返回 $[d, B, A - Bc]$

不用死记，一行就能推出来（板书推的就是这个）：

```
d = A·b + B·r，把 r 换成 a − c·b   →   d = B·a + (A − B·c)·b
```

### 怎么用

求 $b^{-1} \bmod N$：跑 $\mathrm{ExtGCD}(N, b)$，得到 $[1, X, Y]$，则 $b^{-1} = Y$（$Y$ 是负数就加上 $N$）。算具体的数（比如 $3^{-1} \bmod 17$），手算就行，结果和跑代码一样。

## 8. $\mathbb{Z}_n$ 与 $\mathbb{Z}^*_n$（复习）

> 出处：K&L §8.1.2、§8.1.4（书页 289、295–296）；板书 ⑦；已在 [有限域笔记](../../homework/hw1/notes-finite-fields.md) 学过

一共就两个集合。

### $\mathbb{Z}_n$：mod $n$ 下所有可能的余数

```
Z_n  = {0, 1, ..., n−1}
Z_12 = {0, 1, ..., 11}       ← 像钟表，12 点就是 0
```

### $\mathbb{Z}^*_n$：和 $n$ 互素的数，也就是有逆元的数（第 6 步）

$\mathbb{Z}^*_n = \{r \in \mathbb{Z}_n \mid \gcd(r, n) = 1\}$

```
Z*_12 = {1, 5, 7, 11}         0、2、3、4、6、8、9、10 和 12 有公因数，挖掉
Z*_17 = {1, 2, ..., 16}       17 是素数，只挖掉 0
```

大白话：$\mathbb{Z}_n$ 是全部的数；$\mathbb{Z}^*_n$ 是能当除数的那些数，因为它们都有逆元，除以它就是乘以它的逆元。0 永远不在 $\mathbb{Z}^*_n$ 里。

### $\mathbb{Z}^*_n$ 里有几个数：$\varphi(n)$（欧拉函数）

```
n 是素数 p：              φ(p) = p − 1
n = p·q（两个不同素数）：  φ(n) = (p − 1)(q − 1)
```

迷你 RSA 里的 20 就是这么来的：$\varphi(33) = (3-1)(11-1) = 20$。私钥 $7 = 3^{-1} \bmod 20$，就是在 mod $\varphi(n)$ 下求逆元。Lec 9 细讲。

**预告**：$\mathbb{Z}^*_n$ 里的数相乘，结果还在 $\mathbb{Z}^*_n$ 里，而且每个数都有逆元。这就是 Lec 9 要讲的"群"。

### 老师板书

```
Z_n = {0, 1, ..., n−1},    Z*_n = { r ∈ Z_n | GCD(r, n) = 1 }
```

## 9. 老师加的：Lattice

> 出处：板书 ⑧；教材不讲

**了解即可**：教材（K&L 第 2 版）不讲格，课程大纲后面也没有专门讲格的课。

### 格是什么

老师在 $I_{ab} = \{Aa + Bb \mid A, B \in \mathbb{Z}\}$ 旁边写了 "Lattice"，意思是 **$I_{ab}$ 就是一个格**。

格 = 给几个"基"，取它们所有的**整数**组合：

```
I_ab：    基是两个数 a, b       →  { A·a + B·b }      数轴上的一排点
二维格：  基是两个向量 u, v     →  { A·u + B·v }      平面上一片整齐的点
```

大白话：从原点出发，只能沿着基**整步整步地走**（也可以倒着走），能走到的所有点就是格。

例子：

```
一维：a = 6，b = 15          →  {..., −6, −3, 0, 3, 6, 9, ...}     数轴上每隔 3 一个点
二维：u = (1,0)，v = (0,1)   →  所有整数坐标的点，就是方格纸上的交叉点
```

### 和第 5 步的联系

第 5 步证明的是：$I_{ab}$ 里最小的正数是 gcd，用欧几里得几步就能算出来。换成格的说法：**一维格里最短的非零向量很好找。**

### 为什么密码学关心格

```
一维格：   找最短非零向量 = 求 gcd     →  简单（欧几里得）
几百维格： 找最短非零向量（SVP）       →  没有快的算法，连量子算法也没有
```

- RSA 的安全性靠"大数分解难"，但量子计算机上的 Shor 算法能快速分解大数，所以 RSA 将来可能不安全。
- 格上的难题目前连量子算法也解决不了，所以格是**后量子密码**（post-quantum cryptography）的基础。2024 年美国 NIST 发布的后量子标准 ML-KEM（Kyber）和 ML-DSA（Dilithium）都基于格。
- Lec 1 提到的同态加密（homomorphic encryption），现在的方案也都基于格。

> 记住一句：$I_{ab}$ 是一维的格；格就是基的所有整数组合；高维格里找最短向量很难，所以格能用来做后量子密码。
